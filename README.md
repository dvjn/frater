# frater

> a self-hosted, ai-native fitness tracker

## Development

The project uses [mise](https://mise.jdx.dev) for the toolchain and the tasks:

```sh
mise install
mise run dev     # live-reload server
mise run check   # format check, Clippy, tests, dependency audit
```
